## 十一、核心专业名词解释（答辩可直接复述）

### 1. 强化学习（RL）
智能体通过与环境交互，依据奖励信号学习策略，以最大化长期累计回报。

### 2. 智能体（Agent）
做决策的主体。项目里包括 `Random/Heuristic/Minimax/MCTS/DQN/A2C/PPO/BC/AZ` 等。

### 3. 环境（Environment）
规则系统。这里是 Mini Amazons：棋子移动 + 射箭封锁 + 终局判定 + 奖励反馈。

### 4. 自博弈（Self-play）
同类或同源策略相互对战来生成训练数据，是对抗博弈中常见训练方式。

### 5. 奖励重构（Reward Shaping）
在终局奖励之外加入中间引导信号（如机动性、中心控制），帮助学习更稳定更快。

### 6. 动作剪枝（Action Pruning）
在大量合法动作中先筛掉低价值动作，只保留 top-k 或按比例保留，降低搜索/学习难度。

### 7. DQN / A2C / PPO
1. DQN：值函数类深度强化学习，学习 Q(s,a)。
2. A2C：Actor-Critic 同步更新，兼顾策略与价值。
3. PPO：限制策略更新步长，训练更稳定。

### 8. PER（Prioritized Experience Replay）
按 TD 误差优先采样“更有学习价值”的经验，提高样本利用率。

### 9. n-step return
把多步累计回报用于更新，缓解单步回报过短视的问题。

### 10. MCTS / Minimax / Heuristic
1. MCTS：蒙特卡洛树搜索，基于采样扩展搜索树。
2. Minimax：极大极小搜索，适合对抗博弈的博弈树分析。
3. Heuristic：人工设计规则评分，快速但上限受规则质量限制。

### 11. AlphaZero-style（AZ）
“策略价值网络 + MCTS + 自博弈”框架，属于搜索与学习融合方法。

### 12. BC from MCTS（行为克隆）
用 MCTS 作为教师生成数据，再监督学习学生策略网络。

### 13. Arena 自动对弈
后台批量让多个智能体互打，输出逐局明细和汇总统计，是“持续评估”模块。

### 14. 泛化实验（Generalization）
在分布扰动场景（如随机障碍）下评估模型鲁棒性，验证是否“只会背训练分布”。

### 15. Rolling Win Rate
滚动窗口胜率曲线，用于观察训练过程中的趋势和稳定性，而非只看单点结果。
