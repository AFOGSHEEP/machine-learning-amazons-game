## 题目
基于机器学习的亚马逊棋博弈对抗研究

## 一、研究背景与意义
亚马逊棋（Game of Amazons）具有高分支因子、动作结构复杂（移动+射箭阻塞）和强对抗特征，是典型的智能博弈研究对象。相比围棋、象棋等固定单步动作棋类，亚马逊棋每回合动作空间更大、局面演化更剧烈，更适合用于研究多智能体对抗、搜索与学习融合。

本课题的工程意义在于：构建一个“可复现、可扩展、可对比”的博弈实验平台；本课题的学术意义在于：通过多方法并行对比（规则/搜索/强化学习/搜索+学习），观察不同方法在复杂离散博弈中的性能上限、收敛稳定性与计算代价，为后续优化与论文分析提供证据链。

## 二、国内外研究现状（结合本课题路线）
目前博弈智能体主要有三条主路线：
1. 规则/搜索路线：启发式策略、Minimax、MCTS，优点是可解释性强、短期效果稳定；缺点是计算代价高、泛化弱。
2. 强化学习路线：DQN、A2C、PPO 等，优点是可通过自博弈持续改进；缺点是训练成本高、稳定性受超参数影响大。
3. 搜索-学习融合路线：AlphaZero 系列（MCTS + Policy/Value 网络），兼具搜索深度与学习能力，但工程复杂度和算力需求更高。

本课题当前已覆盖以上三条路线，并完成了长程训练与批量评估，具备继续深化到更前沿方法的基础。

## 三、研究目标
1. 构建亚马逊棋（Mini Amazons）对抗环境与统一评估框架。
2. 完成多类智能体实现与对抗比较，包括：
   - 规则/搜索类：Random、Heuristic、Minimax、MCTS；
   - 学习类：Q-learning、DQN(DoubleDQN)、A2C、PPO、BC-from-MCTS、AlphaZero-style。
3. 基于 GPU 完成长程训练与统计评估，输出可直接用于论文的图表与结论。
4. 形成可展示的可视化成果（训练曲线、矩阵热图、胜率置信区间图、排名图），并预留交互式对弈演示界面扩展。

## 四、研究内容与技术路线
### 4.1 系统模块
1. 环境模块：状态编码、合法动作生成、终局判定、奖励反馈。
2. 智能体模块：多算法统一接口（`select_action(state, legal_actions)`）。
3. 训练模块：自博弈训练、模型保存、日志记录、断点可扩展。
4. 评估模块：对随机评估、模型互评矩阵、结果汇总与可视化。

### 4.2 技术路线
1. 完成规则正确性验证与基线闭环（Q-learning）。
2. 接入深度强化学习（DQN/A2C/PPO）并进行 GPU 训练。
3. 接入搜索与融合方法（MCTS、BC-from-MCTS、AlphaZero-style）。
4. 开展分层实验：快速版（小局数）-> 统计版（30/40 局）-> 长程训练结果汇总。
5. 输出论文图组与分析结论。

## 六、方法年代与技术定位（你问的“是什么时代的方法”）
下面是本课题已用方法的大致“方法年代”与定位：

1. Q-learning（1989）
- 时代：经典强化学习早期方法。
- 定位：基线、可解释、易实现。

2. DQN / DoubleDQN（2013~2015）
- 时代：第一代深度强化学习代表。
- 定位：深度值函数学习主线，工程成熟。

3. A2C（2016）
- 时代：策略梯度与价值学习结合的经典方法。
- 定位：稳定性较好、训练速度快于复杂二阶方法。

4. PPO（2017）
- 时代：近年最常用的通用强化学习算法之一。
- 定位：工业/学术常用强基线，稳健实用。

5. MCTS（2006起广泛使用）
- 时代：现代博弈搜索核心方法。
- 定位：强规则基线、解释性强。

6. AlphaZero-style（2017）
- 时代：搜索+学习融合的里程碑路线。
- 定位：本课题中的“高阶方法”与亮点。

7. BC-from-MCTS（监督模仿+教师数据）
- 时代：模仿学习路线（长期发展），在现代 RL 中常作为 warm-start。
- 定位：低风险高可解释的教师-学生范式。

结论：你当前方法覆盖了“经典 -> 现代深度RL -> 搜索融合”的主干，已经足够支撑本科毕设深度。

## 七、是否还能用更前沿的方法？（可以，而且值得）
可以，建议按“可落地性优先”分层推进：

### 第一优先级（强烈推荐，能较快落地）
1. **PPO + Action Masking 强化**（你已有基础）
2. **Population Based Self-Play（群体自博弈）**
3. **Elo/TrueSkill 驱动对手池采样**
4. **Curriculum Learning（课程学习）**：从低复杂度局面逐步升级

### 第二优先级（更前沿，但工程量更大）
1. **MuZero 思路（模型学习+搜索）**
2. **Gumbel/改进 MCTS**
3. **Transformer policy for board games**
4. **Offline RL / Reanalyse**（利用历史对局数据）

本科毕业设计建议：优先把第一优先级做扎实，再在“展望”中写第二优先级。

## 八、当前问题与改进方向
1. 规则/搜索基线（尤其 Minimax）仍然强，深度模型未全面超越。
2. AlphaZero 阶段结果波动，说明训练预算和参数仍需优化。
3. 评估仍可进一步扩大样本量（40 -> 80/100）增强统计稳定性。

对应改进：
- 增加训练轮次与对手池机制；
- 优化奖励（机动性、封锁收益、终盘价值）；
- 做多随机种子实验并报告置信区间。
