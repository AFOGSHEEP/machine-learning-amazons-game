# 开题报告：基于机器学习的亚马逊棋博弈对抗研究

> 文档定位：开题阶段材料（历史快照）。  
> 当前实现与可执行能力请以 `docs/13_实现对照总表_UI_CLI_Scripts_Results.md` 为准。

## 一、研究背景与意义

亚马逊棋（Game of Amazons）具有高分支因子、长时序规划和强对抗性，是验证机器学习博弈能力的典型任务。相较传统棋类，其“移动+射箭阻塞”机制使状态转移更复杂，适合开展多智能体对抗研究。

本课题通过“博弈环境设计 + 强化学习训练 + 对抗评估”的闭环实现，为毕业设计提供从理论到工程的完整路径。

## 二、研究目标

1. 设计并实现亚马逊棋对抗环境，支持状态表示、合法动作生成、奖励反馈与终止判定。
2. 实现强化学习智能体（Q-learning基线），完成自博弈训练。
3. 设计对照实验（随机策略、启发式策略），评估模型有效性。
4. 输出训练日志、胜率统计、实验分析与论文文稿。

## 三、研究内容

1. 博弈环境模块
- 状态：棋盘占位、双方棋子位置、轮次信息
- 动作：棋子皇后走法移动 + 射箭阻塞
- 奖励：终局胜负奖励 + 过程步惩罚

2. 智能体模块
- 策略：epsilon-greedy
- 学习：时序差分更新（Q-learning）
- 扩展：DQN/PPO（作为后续对比）

3. 对抗模块
- 自博弈训练
- 对随机策略评估
- 统计胜率、平局率、回报曲线

## 四、技术路线

1. 构建 Mini Amazons 环境并验证规则正确性。
2. 完成 Q-learning 训练闭环。
3. 进行对抗评估与参数敏感性分析。
4. 对照文献讨论方法优缺点，并提出扩展方向。

## 五、可行性分析

1. 工程可行：Python 环境即可完成训练与评估。
2. 理论可行：强化学习与博弈论有成熟文献支持。
3. 时间可控：先完成可运行基线，再逐步扩展深度模型。

## 六、预期成果

1. 亚马逊棋机器博弈系统源码。
2. 模型文件与训练/评估结果。
3. 开题、中期、结题与答辩材料。
4. 论文正文与参考文献体系。

## 七、进度安排

1. 第1-2周：文献调研、需求分析、开题。
2. 第3-5周：环境与基线智能体实现。
3. 第6-8周：Q-learning自博弈训练与调参。
4. 第9-10周：评估与图表分析。
5. 第11-13周：论文写作与答辩准备。
