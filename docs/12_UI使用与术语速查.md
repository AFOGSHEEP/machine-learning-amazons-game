# UI 使用与术语速查（答辩版）

## 1. UI 现在能做什么

入口：`app/demo_streamlit.py`（运行后访问 `http://localhost:8501`）

### A. 对弈
- 选择不同智能体互相对战（规则类 / 学习类 / AZ/BC）。
- 单步执行、自动对弈、一步到终局。
- 实时展示棋盘与胜负。

### B. 日志与回放
- 回放历史局面，按回合定位关键决策。
- 导出案例到 `results/cases/*.json`（可追溯）。
- 调用本地 Ollama 对对局进行策略点评。

### C. 训练监控
- 自动读取 `results/*log*.csv`。
- 展示 reward / win rate / epsilon / loss / entropy / turns 等曲线。

### D. 一键实验
- 一键创新训练（DQN + 奖励重构 + 剪枝 + PER + n-step）。
- 一键 Arena 批量自动对战。
- 一键生成 Arena 分析图。
- 单按钮全流程：训练 -> Arena -> 出图（后台任务）。

## 2. 常见专业名词（短定义）

1. **强化学习（RL）**：通过奖励信号学习策略，最大化长期收益。
2. **Agent**：做决策的算法体（如 DQN、PPO）。
3. **Environment**：规则与反馈系统（这里是 Mini Amazons）。
4. **Self-play**：智能体与自身/同类对战以学习。
5. **Reward Shaping**：额外中间奖励，提升训练效率和稳定性。
6. **Action Pruning**：从合法动作中筛选高分动作，降低分支复杂度。
7. **DQN**：学习动作价值函数 Q(s,a) 的深度方法。
8. **A2C**：Actor-Critic，同步更新策略与价值。
9. **PPO**：限制策略更新幅度，稳定训练。
10. **PER**：优先经验回放，优先学习高误差样本。
11. **n-step return**：多步回报更新，减轻短视问题。
12. **MCTS**：基于采样的树搜索方法。
13. **Minimax**：对抗博弈中的极大极小搜索。
14. **AlphaZero-style**：神经网络 + MCTS + 自博弈融合框架。
15. **BC from MCTS**：用 MCTS 结果做监督学习。
16. **Arena**：后台批量互打评估系统。
17. **Generalization**：扰动场景下的鲁棒性评估。
18. **Rolling Win Rate**：滑动窗口胜率趋势线。
