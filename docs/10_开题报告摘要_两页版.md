# 开题报告摘要（两页向）

## 一、课题名称
基于机器学习的亚马逊棋博弈对抗研究

## 二、研究背景与问题
亚马逊棋具备高分支因子、长时序决策和强对抗特征，是检验智能决策能力的典型博弈任务。与传统棋类不同，其每回合包含“移动+射箭阻塞”双阶段动作，导致状态转移复杂、策略学习难度更高。  
本课题的核心问题是：在相同博弈环境下，不同类型智能体（规则、搜索、强化学习、搜索-学习融合）性能差异如何？哪些方法在给定算力下更稳定、更具实用价值？

## 三、研究目标
1. 构建可复现的 Mini Amazons 对抗环境与统一评估框架。  
2. 实现多类智能体并开展系统对比，覆盖：
   - 规则/搜索：Random、Heuristic、Minimax、MCTS
   - 学习方法：Q-learning、DQN(DoubleDQN)、A2C、PPO
   - 融合方法：BC-from-MCTS、AlphaZero-style  
3. 完成 GPU 长程训练与统计评估，形成可用于论文的图表与结论。  
4. 输出可视化分析与演示能力（曲线、热图、胜率置信区间、交互对弈 Demo）。

## 四、已完成工作（阶段成果）
### 1. 工程系统
- 已完成环境、训练、评估、可视化、文档全链路。
- 已统一智能体接口，支持跨方法自动对战与批量评估。
- 已在 RTX 4060 + CUDA 环境下完成长程训练。

### 2. 长程训练
- DQN-long：3000 episodes

## 五、阶段性结论
1. 学习型方法对随机策略有显著提升，说明训练闭环有效。  
2. 在当前设定下，强规则/搜索基线（尤其 Minimax）仍具明显优势。  
3. AlphaZero 路线已打通，但受训练预算与超参数影响，性能仍有优化空间。  
4. 多方法并行对比的实验设计已具备论文可信度基础（含 n30/n40 统计版矩阵）。

## 六、方法年代与技术定位
- Q-learning（1989）：经典基线  
- DQN/DoubleDQN（2013-2015）：第一代深度 RL 核心  
- A2C（2016）、PPO（2017）：现代常用强化学习主力  
- MCTS（2006 后广泛应用）：搜索强基线  
- AlphaZero-style（2017）：搜索+学习融合代表  
- BC-from-MCTS：模仿学习与强化学习衔接路径

结论：本课题已覆盖“经典 -> 现代深度 RL -> 融合路线”，满足本科毕设深度要求，并具备进一步前沿扩展基础。

## 七、下一步计划
1. 增强训练稳定性：多随机种子、参数网格、奖励重构。  
2. 补充统计可信度：扩大高局数对战并报告置信区间。  
3. 增加答辩展示能力：上线交互式对弈 Demo（支持多模型对战与棋盘回放）。  
4. 完成论文实验章节整理：主结果、对照组、消融实验、局限分析与展望。

## 九、今晚演示快速启动（给老师看）
1. 在项目根目录打开终端，先进入环境并安装依赖：  
   `pip install -r requirements.txt`
2. 启动交互 Demo：  
   `streamlit run app/demo_streamlit.py --server.port 8503`
3. 浏览器打开：  
   `http://localhost:8503`
4. 演示建议：  
   - 侧边栏勾选“使用排行榜预设（推荐）”；  
   - 先做 `mm vs dqnL` 或 `mm vs az2` 对比；  
   - 若当前棋盘不是 6x6，系统会自动切回 6x6 再加载学习型智能体。  
5. 注意：  
   - 学习型模型（Q/DQN/A2C/PPO/BC/AZ）当前按 6x6 训练；  
   - 非学习型（random/heuristic/minimax/mcts）可用于更大棋盘演示。
